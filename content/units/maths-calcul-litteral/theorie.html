Le vocabulaire

Une expression littérale contient des lettres qui remplacent des nombres : 3x² − 5x + 2.

  • Les termes sont les morceaux séparés par + ou − : 3x², −5x et 2.
  • Le coefficient est le nombre devant les lettres : dans −5x, c'est −5. Dans x, c'est 1.
  • Des termes semblables ont exactement les mêmes lettres avec les mêmes exposants : 4x et −7x, ou 2x² et x². Mais pas 2x et 2x².

Conventions : on n'écrit pas le signe · devant une lettre (3 · x = 3x) et on n'écrit pas le coefficient 1 (1x = x).

Les trois gestes

Réduire5x + 2x = 7xregrouper les termes semblables
Développer3(x + 4) = 3x + 12un produit devient une somme
Factoriser3x + 12 = 3(x + 4)une somme devient un produit

Développer et factoriser sont deux chemins inverses : on peut toujours vérifier une factorisation en la développant.

Calculer la valeur d'une expression

On remplace chaque lettre par sa valeur, entre parenthèses si elle est négative, puis on respecte les priorités : puissances, puis multiplications, puis additions et soustractions.

Calcule 2x² − 3x + 1 pour x = −4 :

2 · (−4)² − 3 · (−4) + 1
= 2 · 16 + 12 + 1
= 32 + 12 + 1 = 45

Réduire

Une somme : on additionne les coefficients des termes semblables.

5x + 3 − 2x + 7
= (5x − 2x) + (3 + 7)
= 3x + 10

Un produit : on multiplie les nombres entre eux et les lettres entre elles.

3x · 4x = 3 · 4 · x · x = 12x²
2x · (−5y) = −10xy

Développer : la distributivité

Distributivité simple

k(a + b) = ka + kb

4(2x − 3) = 4 · 2x + 4 · (−3) = 8x − 12
x(x + 5) = x · x + x · 5 = x² + 5x

Signe − devant une parenthèse : il change le signe de chaque terme.

−(x − 6) = −x + 6
−2(3x − 1) = (−2) · 3x + (−2) · (−1) = −6x + 2

Double distributivité

(a + b)(c + d) = ac + ad + bc + bd

Chaque terme de la 1re parenthèse multiplie chaque terme de la 2e : 4 produits.

(x + 2)(x − 5)
= x · x + x · (−5) + 2 · x + 2 · (−5)
= x² − 5x + 2x − 10
= x² − 3x − 10

Explore : l'aire d'un rectangle

Un rectangle de côtés (a + b) et (c + d) se découpe en 4 rectangles. Son aire est la somme des 4 aires : c'est la double distributivité. Bouge les curseurs.

Les identités remarquables

Niveau Expert. Ce sont des doubles distributivités à connaître par cœur.

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
(a − b)(a + b) = a² − b²
(x + 3)² = x² + 2 · x · 3 + 3² = x² + 6x + 9
(2x − 1)(2x + 1) = (2x)² − 1² = 4x² − 1

Factoriser : la mise en évidence

On cherche le plus grand facteur commun à tous les termes (un nombre, une lettre, ou les deux) et on le met devant la parenthèse.

12x + 18 = 6 · 2x + 6 · 3 = 6(2x + 3)
6x² + 9x = 3x · 2x + 3x · 3 = 3x(2x + 3)

Complètement : 2(6x + 9) est égal, mais 6x + 9 peut encore être factorisé. Ce n'est pas fini.

Avec les identités : x² − 16 = (x − 4)(x + 4) et x² + 10x + 25 = (x + 5)².

Les pièges à éviter

  • On n'additionne que des termes semblables : 3x + 2 reste 3x + 2 (jamais 5x).
  • x + x = 2x, mais x · x = x². Et 2x · 3x = 6x², pas 6x.
  • Le facteur devant la parenthèse multiplie tous les termes : 5(x + 4) = 5x + 20, pas 5x + 4.
  • Un signe − devant une parenthèse change tous les signes : −(2x + 5) = −2x − 5.
  • (x + 3)² n'est pas égal à x² + 9 : il manque le double produit 6x.
  • Pour x = −3 : x² = 9 mais −x² = −9. Mets toujours la valeur entre parenthèses.

Dans les exercices, tape x^2 pour écrire x². Les espaces et l'ordre des termes n'ont pas d'importance : 6x + 15 et 15 + 6x sont acceptés.
