| Gaz | Sources principales | Effet |
|---|---|---|
| **Vapeur d'eau** (H₂O) | Évaporation naturelle | Le plus abondant ; augmente quand l'air se réchauffe |
| **Dioxyde de carbone** (CO₂) | Charbon, pétrole, gaz, déforestation, ciment | Principal gaz émis par les humains ; reste des siècles |
| **Méthane** (CH₄) | Élevage de ruminants, rizières, décharges, fuites de gaz | ≈ 28 fois plus réchauffant que le CO₂, reste ≈ 12 ans |
| **Protoxyde d'azote** (N₂O) | Engrais azotés | ≈ 270 fois le CO₂ |
| **Gaz fluorés** | Climatiseurs, frigos, pompes à chaleur | Des milliers de fois le CO₂ |

## Retenir les associations

- Vache, riz, décharge → **méthane**
- Engrais → **protoxyde d'azote**
- Voiture, chauffage au mazout, centrale à charbon, forêt brûlée, ciment → **CO₂**
- Frigo, climatiseur → **gaz fluorés**
